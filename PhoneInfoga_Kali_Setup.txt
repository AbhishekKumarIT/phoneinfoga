PhoneInfoga on Kali Linux - Quick Setup Notes

1. Update Kali
sudo apt update

2. Install basic tools
sudo apt install -y curl wget tar

3. Download PhoneInfoga
curl -L "https://github.com/sundowndev/phoneinfoga/releases/download/v2.0.8/phoneinfoga_$(uname -s)_$(uname -m).tar.gz" -o phoneinfoga.tar.gz

4. Extract
tar xvf phoneinfoga.tar.gz

5. Check version
./phoneinfoga version

6. Install system-wide
sudo mv phoneinfoga /usr/local/bin/

7. Check installation
phoneinfoga version

8. Scan a phone number
phoneinfoga scan -n "+91XXXXXXXXXX"

Replace +91XXXXXXXXXX with a number you are authorized to investigate.

9. Start the web interface
phoneinfoga serve

Then open:
http://localhost:5000

Notes:
- PhoneInfoga is free and open-source.
- Some scanners/services may require separate accounts, API keys, or have their own limits.
- PhoneInfoga does not provide private carrier records, live location, call history, or other confidential information.
- Treat OSINT matches as leads and independently verify them.
